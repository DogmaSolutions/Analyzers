# DSA036

A `Regex` object is created at runtime with a pattern (and options, timeout) that are compile-time constants or effectively immutable values. Each such creation allocates a new `Regex` instance and re-parses the pattern from scratch. When the pattern never changes, the `Regex` should be created once in a `private static readonly` field and reused across all invocations.

## 💡 Rationale

This rule fires when a `Regex` object is created at runtime — either via `new Regex(...)` or via a static `Regex` method (`IsMatch`, `Match`, `Matches`, `Replace`, `Split`, `Count`, `EnumerateMatches`) — and all parameters that define the regex (pattern, options, timeout) are compile-time constants or effectively immutable values. The only exception is the **matched input string** (and the `replacement`/`evaluator` for `Replace`), which is naturally dynamic.

Each `new Regex(pattern)` call allocates a new object and parses the pattern from scratch, constructing an internal finite automaton. When the pattern never changes, this work is redundant and wasteful. The regex should be created once in a `private static readonly` field and reused across all invocations.

Static `Regex` methods (`Regex.IsMatch(input, pattern)`, etc.) internally create and cache `Regex` instances, but the cache is bounded (15 entries by default). In high-throughput code with many distinct patterns, cache evictions cause repeated parsing. Pre-allocating a static field eliminates cache pressure entirely.

An argument is considered **effectively constant** when it is a string literal, a `const` field or local, a `static readonly` field, an enum literal or bitwise combination (e.g. `RegexOptions.IgnoreCase | RegexOptions.Compiled`), or a local initialized from any of those and never reassigned in the enclosing scope. It is **not** constant when it is a method parameter, a method/property call result (including `TimeSpan.FromSeconds(...)`), an instance field (even `readonly`, since it varies per instance), or a variable that is reassigned or passed by `ref`/`out`. A creation already inside a `static readonly` field initializer is never flagged.

## 🔐 Security implications

Unbounded `Regex` allocations inside a tight loop or a request-processing pipeline can be exploited for denial-of-service: an attacker who can trigger the code path repeatedly forces the server to waste CPU cycles on redundant pattern parsing and increases GC pressure.

- **CWE-400: Uncontrolled Resource Consumption** — redundant parsing and allocation waste CPU and memory on every invocation.
- **CWE-405: Asymmetric Resource Consumption (Amplification)** — a cheap request can amplify into disproportionate server-side work.
- **IEC 62443-3-3, FR 7 (Resource Availability)** — hoisting the pattern to a single parse ensures computational resources are not wasted on redundant object construction.

## ⚡ Performance Impact

- **`new Regex(pattern)`**: allocates a new object and parses the pattern on every call. In a loop of `N` iterations this is `O(N × P)`, where `P` is the pattern-parsing cost.
- **`Regex.IsMatch(input, pattern)`** (static methods): uses an internal LRU cache of 15 entries. If the cache is full, the least-recently-used pattern is evicted and must be re-parsed on the next call.
- **Static readonly field**: the pattern is parsed once at class initialization; all subsequent uses are `O(1)` field access with zero cache pressure.

## 🔦 Code sample

```csharp
public class DataProcessor
{
    public bool ValidateCode_NotOk(string input)
    {
        // this WILL trigger the rule: pattern is a constant string literal
        var regex = new Regex(@"\d{3}-\d{4}", RegexOptions.Compiled);
        return regex.IsMatch(input);
    }

    public string SanitizeText_NotOk(string input)
    {
        // this WILL trigger the rule: static Regex method with constant pattern
        return Regex.Replace(input, @"\s+", " ");
    }

    // fixed: hoisted to static readonly fields
    private static readonly Regex _codeRegex = new Regex(@"\d{3}-\d{4}", RegexOptions.Compiled);
    private static readonly Regex _whitespaceRegex = new Regex(@"\s+");

    public bool ValidateCode_Ok(string input) => _codeRegex.IsMatch(input);

    public string SanitizeText_Ok(string input) => _whitespaceRegex.Replace(input, " ");
}
```

## ℹ️  Matched patterns (code is NOT OK)

```cs
// new Regex with literal pattern:
var regex = new Regex(@"\d+");

// new Regex with literal pattern and options:
var regex = new Regex(@"\d+", RegexOptions.Compiled | RegexOptions.IgnoreCase);

// new Regex with a const variable:
const string pattern = @"\d+";
var regex = new Regex(pattern);

// new Regex with a non-mutated local variable:
var pattern = @"\d+";
var regex = new Regex(pattern);  // pattern is never reassigned

// Static Regex methods with a constant pattern:
Regex.IsMatch(input, @"\d+");
Regex.Match(input, @"\d+");
Regex.Replace(input, @"\d+", "X");
Regex.Split(input, @"\s+");
Regex.Matches(input, @"\d+");
```

## ✅ Not matched patterns (code is OK)

```cs
// Already in a static readonly field:
private static readonly Regex _regex = new Regex(@"\d+");

// Pattern comes from a method parameter:
public bool Check(string input, string pattern) => new Regex(pattern).IsMatch(input);

// Pattern comes from a method call result:
var regex = new Regex(GetPattern());

// Pattern local variable is reassigned:
var pattern = @"\d+";
if (strict) pattern = @"^\d+$";
var regex = new Regex(pattern);

// Options come from a parameter:
public bool Check(string input, RegexOptions opts) => new Regex(@"\d+", opts).IsMatch(input);
```

## 🛠️ Included Code Fixer and Mitigation

The **Extract to private static readonly field** code fix hoists the flagged `Regex` creation to a `private static readonly` field at the class level and rewrites the call site to reuse it.

**For `new Regex(...)` constructor calls:**
```cs
// Before:
public class Validator
{
    public bool Check(string input)
    {
        var regex = new Regex(@"\d+", RegexOptions.Compiled);
        return regex.IsMatch(input);
    }
}

// After:
public class Validator
{
    private static readonly Regex _regex = new Regex(@"\d+", RegexOptions.Compiled);
    public bool Check(string input)
    {
        var regex = _regex;
        return regex.IsMatch(input);
    }
}
```

**For static `Regex` method calls:** the pattern/options move into a `static readonly` field and the call becomes an instance call on that field.
```cs
// Before:
return Regex.IsMatch(input, @"\d+", RegexOptions.IgnoreCase);

// After:
private static readonly Regex _regex = new Regex(@"\d+", RegexOptions.IgnoreCase);
// ...
return _regex.IsMatch(input);
```
